# ToDo App | Lux Aesthetic
A minimalist and high-performance task management application built with Django. The interface follows the Lux theme (Bootswatch), providing a sleek, professional look focused on clarity and discipline.

# Key Features
Full CRUD Functionality: Create, view, edit, and delete tasks seamlessly. 🚀

Tag Management: Organize your workflow by categorizing tasks (e.g., Studies, Sport, Work). 🏷️

Deadline Tracking: Integrated HTML5 Date widget for precise scheduling. 📅

Lux Design Language: A clean, high-contrast UI designed for focus. 🎨

# Tech Stack
Backend: Python 3.x, Django 5.x 🐍

Database: SQLite (Local development) 🗄️

Frontend: Bootstrap 5, Bootswatch (Lux Theme) ✨

Version Control: Git 🔧

# Installation & Setup
Clone the repository:
git clone https://github.com/Kronev1i/Todo-List.git
cd Todo-List

Set up a virtual environment:
python -m venv .venv
.venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

Apply migrations:
python manage.py migrate

Run the development server:
python manage.py runserver
